Практическая работа 6.3

Тема: динамические библиотеки

В данной работе доработан калькулятор из задания 2.3.
Математические функции загружаются из динамических библиотек
во время работы программы.

Структура проекта:

src/
    main.c
    io_utils.c
    loader.c
    sum.c
    sub.c
    mul.c
    div.c

include/
    io_utils.h
    loader.h

libs/
    libsum.so
    libsub.so
    libmul.so
    libdiv.so

tests/
    test_cal.c


Каждая математическая операция находится в отдельной
динамической библиотеке:

libsum.so - сложение
libsub.so - вычитание
libmul.so - умножение
libdiv.so - деление


Сборка проекта:

make


Запуск программы:

./build/task6_3 ./libs


При запуске программа получает путь к каталогу с библиотеками,
находит в нём .so файлы и загружает необходимые функции
с помощью dlopen() и dlsym().


Выход из программы:

Для завершения работы необходимо ввести:

q


Запуск тестов:

./run_tests


Очистка файлов сборки:

make clean
