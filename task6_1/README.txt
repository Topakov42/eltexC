Практическая работа 6.1

Тема: статическая библиотека

В работе доработан список контактов из задания 4.1.
Функции и структуры для работы с двухсвязным списком
вынесены в статическую библиотеку liblist.a.

Структура проекта:

include/
    list.h
    ui.h
    file_loader.h

src/
    main.c
    list.c
    ui.c
    file_loader.c

test/
    test.c

build/
    liblist.a
    task6_1
    test_runner


Сборка:

make


Запуск программы:

./build/task6_1


Запуск тестов:

./build/test_runner


Очистка файлов сборки:

make clean


Статическая библиотека собирается из файла list.c
и используется основной программой и тестами.
